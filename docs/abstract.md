# Project Abstract

TASKFLOW is a comprehensive web-based Task Management and Workflow System developed to streamline task assignment, track operational progress, and enforce deadline adherence within small teams and academic environments. Traditional informal methods of task management, such as email threads and static spreadsheets, frequently result in miscommunications, lost accountability, and disorganized workflows. 

The proposed system mitigates these issues by offering a centralized, role-based platform. Administrators are equipped with tools to create tasks, assign them to specific users, dictate priority levels, and establish strict deadlines. A key innovation of the system is its robust dependency management module, which prevents tasks from being initiated until their designated prerequisites are successfully completed.

The application incorporates a structured task lifecycle (Assigned → In Progress → Completed) to provide real-time visibility into operational bottlenecks. To handle real-world scheduling conflicts, the system features a systematic postponement workflow, allowing users to formally request deadline extensions that administrators can approve or reject. This process is supplemented by a comprehensive auditing module that logs every interaction, status change, and comment, ensuring complete traceability.

Developed using Java 21, Jakarta Servlet/JSP architecture, and MySQL, the system eschews heavy frameworks in favor of a clean, performant, and maintainable MVC footprint. The result is a highly functional, responsive, and secure web application that centralizes task management, significantly enhances organizational accountability, and ensures workflows are executed in the correct sequence.

# Objectives

The primary objective of the TASKFLOW project is to develop a centralized, reliable, and user-friendly web application for managing tasks and workflows. 

The specific objectives include:

1. **Centralize Task Management:** Provide a unified platform where administrators can create, track, and manage all operational tasks.
2. **Assign Tasks efficiently:** Allow administrators to delegate tasks to specific users with clear priorities and descriptions.
3. **Track Task Status:** Implement a strict, observable lifecycle (Assigned → In Progress → Completed) so that progress is transparent at all times.
4. **Manage Deadlines:** Provide clear visibility into due dates, automatically flagging tasks as overdue when deadlines are breached.
5. **Handle Postponement Requests:** Establish a formal workflow for users to request deadline extensions, requiring administrative approval or rejection with documented reasoning.
6. **Manage Task Dependencies:** Ensure workflow integrity by allowing administrators to link tasks as prerequisites, preventing users from starting tasks out of order.
7. **Provide Notifications:** Deliver real-time, in-app notifications for critical events such as new task assignments and postponement request verdicts.
8. **Maintain Task History:** Automatically log an immutable audit trail of all actions (creation, assignment, status changes, comments) for accountability.
9. **Provide Dashboards:** Deliver role-specific dashboards that aggregate relevant statistics and recent activity feeds for quick insights.
10. **Provide Search/Filter/Sort Functionality:** Enable users and administrators to quickly locate tasks using robust filtering (by status, priority, user) and dynamic sorting.
